Generated in your browser在你的浏览器里生成

Nothing here is sent anywhere. There is no analytics, no font, no script from another host — the page draws the QR code with a vendored encoder (qr.js, MIT). The address field is prefilled from the URL fragment (the part after #), which browsers never transmit, so a link to this page cannot leak the address it carries to this site or to anyone watching the network.这里的东西不会发送到任何地方。没有统计、没有外部字体、没有来自其它主机的脚本 —— 二维码是页面用仓库内自带的编码器（qr.js，MIT）自己画出来的。地址栏的预填值来自 URL 的片段（# 之后的部分），浏览器从不发送片段，所以把这个页面的链接转给别人， 不会把里面的地址泄露给本站，也不会泄露给任何旁听网络的人。

Get the app first先装上应用#

Before the APK: Tailscale, on both ends装 APK 之前：两端都要有 Tailscale

This app is the client; the network is Tailscale, and it has to be installed on both ends — the computer that runs DSH and the phone or tablet — signed into the same tailnet. The computer's copy comes from tailscale.com/download; the Android app is on Google Play (com.tailscale.ipn). Neither replaces the other: without Tailscale on both ends, the link below has nowhere to go.这个应用是客户端， 网络那半是 Tailscale，而且两端都要装 —— 跑 DSH 的电脑，和手机或平板 —— 并登录同一个 tailnet。电脑端去 tailscale.com/download 下载；安卓端在 Google Play（包名 com.tailscale.ipn）。两者谁也替代不了谁：两端没有 Tailscale，下面这条链接就没有地方可去。

What a link may say — and what it may never say链接可以说什么 —— 以及绝不可以说什么#

Configuration only只带配置

A link may carry: target, port, scheme, path, mode, update, control, node. The app shows the merged result before applying it, and refuses a link whose target its address policy would not let you type by hand.链接可以携带：target、port、scheme、 path、mode、update、 control、node。App 会先显示合并后的结果再应用； 如果某条链接的目标连手动输入都不被地址策略允许，它同样会被拒绝。

Never a credential绝不带凭据

If a link contains any field whose name looks like a credential — authkey, key, token, password, secret — the whole link is refused, and the app says so. A link can be photographed off a screen, so a secret in one is a secret in public. The auth key is typed into the app, or obtained through the control plane's own login.只要链接里出现任何名字像凭据的字段 —— authkey、key、token、 password、secret —— 整条链接都会被拒绝， 并且 App 会说明原因。链接是可能被从屏幕上拍走的，所以链接里的秘密就等于公开的秘密。 认证密钥请在 App 里输入，或通过控制面自己的登录流程取得。

Never silent绝不悄悄生效

A link cannot re-point the app by itself. That is the attack worth designing against — a QR code that quietly aims the app at a stranger's server, so the next thing you type is your key. The app therefore parses, shows, and waits: apply or ignore is your tap.链接本身无法把 App 改指向别处。这正是要防的那条攻击链 —— 一张二维码悄悄把 App 指向陌生人的服务器，你接下来输入的就是自己的密钥。所以 App 的做法是：解析、展示、 然后等你 —— 应用还是忽略，由你点。

Baking a target into your own build把目标写进你自己的构建#

The public build carries no address, on purpose. A private or branded build can pre-fill one, and then nobody has to type anything:公开构建里不带任何地址，这是有意为之。私有构建或定制品牌的构建可以预填一个地址， 这样谁都不用再手输： 

./gradlew assembleDebug -PdefaultTarget=phone.tailnet-name.ts.net:3080 -PdefaultMode=system

The value only *defaults* the first screen — it is never a policy, and once the user saves anything the stored value wins. Those properties are also run through the same parser a link is, so a malformed value degrades to "no default" rather than shipping a broken address. Nothing is committed: the public build's values are empty, and CI checks that they stay that way.这个值只是首次进入时屏幕上的默认值 —— 它永远不是策略；用户一旦保存过任何设置， 就以保存的值为准。这些属性同样会走与链接完全相同的解析器，所以写坏的值会退化成「没有默认值」， 而不是发布一个坏地址。仓库里什么都不提交：公开构建的这三个值恒为空，CI 也会一直检查它们保持为空。
