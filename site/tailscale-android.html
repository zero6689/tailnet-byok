Which one to install该装哪一个#

If Google Play opens for you: use it — newer versions, and it updates itself. If it does not, and tailscale.com does not either, take the file above. Either way you end up with the same app, package com.tailscale.ipn; only the version and the update habit differ.如果你那里 Google Play 能打开：就用它 —— 版本更新、而且会自己更新。打不开，且 tailscale.com 也打不开，就用上面那个文件。 两条路的包名都是 com.tailscale.ipn，装出来是同一个应用，区别只在版本号和以后怎么更新。

This app, tailnet-byok, is a separate application: it is the client for your own DSH server, and it is used together with Tailscale rather than instead of it. Install Tailscale on both ends — the phone or tablet, and the computer running DSH — and sign both into the same tailnet.本项目 tailnet-byok 是另一个应用：它是你自己那台 DSH 服务器的 客户端，是和 Tailscale 搭配使用，而不是替代它。两端都要装 Tailscale —— 手机或平板，以及跑 DSH 的 电脑 —— 并登录同一个 tailnet。
