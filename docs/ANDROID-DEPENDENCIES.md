# Android and Kotlin dependencies

Every module the release build takes from the Gradle graph, with the licence its
own POM declares. Generated by `./gradlew :app:androidLicenceInventory` from the
`releaseRuntimeClasspath` resolution — not written by hand, and regenerated and
compared in CI the way `THIRD-PARTY-NOTICES.md` is.

The Go modules linked into `libgojni.so` are inventoried separately in
[`THIRD-PARTY-NOTICES.md`](THIRD-PARTY-NOTICES.md). Together the two files are what
describes the contents of the APK.
